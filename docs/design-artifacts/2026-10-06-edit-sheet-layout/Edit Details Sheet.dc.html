03Total turns into New total and the balance line turns into "balance due becomes" without changing height, so the first tap changes the height of nothing. Only the reprice lines arriving make it taller.
04While a new figure loads, the last figure dims under PRICING. The steppers stay live. Only Confirm waits.
05A changed field shows "was 3 hr" under its label. That fits inside the 48px row, so no row grows. The stepper's value slot is a fixed 68px, so "10.5 hr" can't push the − button sideways.
06Setup is a read-only line under Start, since it's set in minutes before the start. Dropping its 48px row, and setting the reprice lines without a bullet indent, lets three lines fit at 320 × 568. Max height is 100dvh − 12px. Longer copy scrolls inside the readout.
