Mobile idiom · phone-first admin · spec 2026-08-13-mobile-admin
  • One fork. 700px, in the app's useIsPhone hook. Never a scattered media query.
  • 44px targets, primary actions in the thumb zone, tabs and sheets pad the safe-area inset.
  • Sheets over dropdowns. Rows you tap, not menus you aim at. Scrim tap closes.
  • No typing. Steppers for counts, chips for status, native pickers for date and time. Free text is a dictation-friendly textarea, last resort.
  • Lists are date-ordered cards, never tables. Status filters and column sorts are desk work.
  • Offline reads, never writes. Cache-served data carries an "as of" staleness line; a failed save keeps input and says so. Nothing queues.
  • No dead ends. Every screen keeps the per-screen Desktop-view escape hatch, and the return pill floats in the thumb zone.
  • Still the OS. Same tokens, both skins, nouns for labels, mono for numbers, no emoji.
