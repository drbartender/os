## What the rebase changed

Every file's net change against main is identical before and after the rebase (compared file by file on the changed lines), except the regenerated sections of ARCHITECTURE.md and three deliberate resolutions:

1. **Payouts, `server/routes/admin/contractorTipPage.js` (POUT-01).** Main's lane staff-page-manager-view made every tip-page action admin-only and hid the Tip Page tab from a manager, which closes the manager path the audit found. The lane's commit therefore dropped its own manager field gate and its Tip Page tab guard and keeps what main lacks: an admin write of the payout fields logs a `tip_handles_change` audit row naming the fields changed, never a handle value. Its test was adapted: a manager gets 403 with nothing written for any body, a preferred name included; against main's route the audit-row case fails (1 of 8). The later commit that shares one allowed set and one eligibility rule for the payroll method (POUT-10) applied unchanged on main's version.
2. **Payments, `server/utils/balanceInvoiceMonitor.js` and `server/utils/balanceScheduler.js` (PAY-01).** Main's lane legal-hold-auto bound the held proposal ids as the second parameter of the monitor's two queries; the audit lane had bound its netting label list as the second parameter of the same queries, and a textual merge left both there. Resolved: the off-ledger labels first, the held ids second (main's), the netting labels third, all three bound at both call sites. In the scheduler both imports stand; main's legal-hold exclusions on the autopay claim and the completion sweep are untouched and the lane's netted balance follows them.
3. **E-signatures, `client/src/pages/admin/userDetail/tabs/DocumentsTab.js` (ESIG-04).** Main added a `showTax` prop to the component; the lane added the agreement's Open and resend actions. Both kept.

Generated docs: at every stop that conflicted only in README.md or ARCHITECTURE.md the base's copy was taken and the generated sections regenerated from that commit's tree, the rule `scripts/merge-lane.sh` applies (the lanes changed those files between the markers only, checked with `gen-docs.js --generated-only`).
