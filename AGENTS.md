# Dr. Bartender OS

This repo is the operating system for a bartending company: proposals, payments, staffing, payroll, client comms.

- Read `.claude/CLAUDE.md` for the rules.
- Read `docs/money-laws.md` before touching anything that moves money.
- Read `docs/dev.md` to run the servers or the tests.
- The repo is public: see the PII rule in `.claude/CLAUDE.md` before writing a doc, a commit message or a fixture.
